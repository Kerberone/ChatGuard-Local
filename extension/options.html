La cartella viene scelta con una finestra di Windows. Se il programma non è collegato, esegui INSTALLA.cmd dal pacchetto e inserisci l'ID visibile in brave://extensions. Nessuna modifica è necessaria alle autorizzazioni dei download di Brave.

Affidabilità e limiti

Nessuna finestra «Salva con nome»: non utilizziamo le funzioni di download del browser. Il programma locale verifica che il file ZIP sia integro prima di confermare il backup.

Dentro ogni ZIP trovi conversazione.json, stato_backup.json, il CSV, il Markdown e gli allegati effettivamente recuperati. Lo stato sarà PARZIALE se mancano file, se l'API non fornisce tutta la cronologia o se alcuni link sono solo temporanei.

Solo le chat aperte: la versione 1.0 non percorre automaticamente tutte le vecchie conversazioni nell'account. I file già scomparsi dal server non possono essere recuperati dall'estensione. Gli endpoint interni di ChatGPT possono cambiare. Non rendere pubblici gli ZIP, perché contengono anche dati personali e metadati.
